# Comandos basicos de Git

git init: crea un repositorio nuevo
git clone <url>: copia un repositorio remoto
git status: muestra el estado de los archivos
git add <archivo>: prepara cambios para el commit
git commit -m "mensaje": guarda los cambios con un mensaje
git branch <nombre>: crea una rama nueva
git checkout <rama>: cambia de rama
git push: envia los commits al repositorio remoto
git pull: trae los cambios del repositorio remoto
